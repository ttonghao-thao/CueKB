# 系统约束与保证范围

更新：2026-10-30。这里描述当前实现边界；质量、负载的执行记录见[任务板](../TASK_BOARD.md)。

## 1. 产品与证据边界

CueKB是多语言原文证据检索系统，不包含生成式回答API、答案模型或自动业务执行。Embedding必配，Reranker可选；未配Reranker不会单独使正常检索降级。多语言是产品范围，各语种质量需独立实测。

PostgreSQL是授权、删除、发布版本和正文权威；OpenSearch是可重建候选投影。最终复验只保证其快照当时的合法性，无法撤回已经发送给调用方的字节；调用方缓存、会话历史和语音重播也要自行处理撤权。

只支持知识库级ACL和每文档唯一default发布指针；产品过滤不是权限，业务版本不是软件适用条件。没有文档ACL、历史版本搜索、多scope发布或无限图遍历；指定版本原件下载不等于能搜索历史版本。

## 2. 归属、完整性和评分

- 同文档、同章节、相邻、提及产品名均不等于同产品归属。自动resolved依赖冻结目录与明确结构/主体属性规则或审核标注；未知/冲突为unknown/ambiguous，不根据query补名。
- 保留已识别结构条件，不保证任意文档的所有远距自然语言例外都能自动识别。复杂扫描件、多页/合并表格和图形仍需真实样本核对；source_spans可空或有限，不能虚构精确cell定位。
- unknown与结构依赖独立：仅有冻结来源、同版本并无明确归属/条件冲突的必要关系可携带unknown条件段；返回仍为unknown。可选近邻不放宽，所有多跳依赖必须在直接关系中核验，否则unresolved。
- context_state=complete只是已识别有限依赖已装入，不是回答充分；`/v2/search`的evidence_status始终unassessed。只有独立`/v2/evidence/query`按facet输出问题级支持状态，两种状态不能互换。
- 多证据覆盖是优化和验收指标，不保证任意复合问题全部召回。没有命中或缺某属性不证明KB客观不存在它。
- adaptive根据字面观察、必要依赖、差异和负载动态选择；query_facets不是语义分类器，观察到词项不证明值已提供。未配置匹配的人工校准文件时不保证自动拒收低相关候选；绑定失配明确报告binding_mismatch，证据充分性始终unassessed。
- RRF使用源名次计算真实融合分数；不同BM25、向量、重排量纲不相加，不等于事实正确概率。可复现依赖冻结语料、发布指针、索引、代码、配置及不可变外部模型修订。
- 语音模型的逐项回答、比例/单位口述、引用和播放需要调用方端到端验收，检索测试不能替代。

## 3. 默认预算与硬上限

| 范围 | 当前值/边界 |
| --- | --- |
| 上传 | 50MiB默认文件大小；TXT/MD为UTF-8；不支持旧DOC |
| V2 query / KB / top_k | 2000字符；最多50 KB；最终最多20 hit |
| V2候选 | keyword/vector默认50，各最高100；relation默认30最高50；每次尝试最终候选列表合计≤250 |
| 关系 | 最多20起点，仅一跳；关系SQL默认100ms；最终复验不重新发现新关系 |
| 补取/重试 | 整请求最多一次扩大召回；版本变化最多重试一次，两次尝试共用deadline和补取额度 |
| Reranker | 窗口至少覆盖top_k且最多100；每次尝试最多一次，版本重试时累计最多两次 |
| context | 默认8块/命中、4000字符/命中、12000字符/响应；只读一跳结构依赖。最终候选每块最多20链接，批量必要依赖读取≤5000个ID；输出最多20组/400依赖节点 |
| 动态选择 | 默认ranked；adaptive显式启用。selection_query最多2000字符，query_facets最多8项/每项200字符；返回数0—top_k，不保证填满 |
| 结构/归属 | 每块最多20引用、8 subjects、20 conditions、64 source_spans；每个请求最多100条必要关系配置；写入拒绝循环/越界/缺失目标 |
| 选择式审核 | 每文档最多10000事实；每页25/最多100；每批最多100决定、每问题最多5候选；每计划最多100个跨页冻结集合；原子批次及修订409；模板最多100个 |
| 处理审核 | KB write；每页默认25、最多100块，offset最多1000000；汇总包含全版本；不返回服务器完整实体快照 |
| V2 evidence bytes | 请求缺省48000，上限128000，另受服务端CUEKB_V2_MAX_EVIDENCE_BYTES；约束实际UTF-8 hits JSON，含重复字段 |
| V2总响应 | 256KiB硬上限；过大明确503，不截断原文伪装成功 |
| 问题级证据 | question/search_query各最多2000字符、50 KB、8 bindings、8 facets、1—5组；facet文本最长500；完整model_view预算32—4096个已登记token；完整响应默认256000字节、可配至1MiB |
| 证据包 | HMAC绑定principal/API Key、KB、内容/ACL修订、input revision及快照；默认30秒，范围5—300秒；复验不回传旧正文 |
| 搜索预算 | CUEKB_SEARCH_DEADLINE_MS默认900ms；模型阶段默认400ms、OS默认500ms；不是已验收P95 |
| V2运行资源 | 默认每API进程16个生产transport租约，最多4个在途配置修订；满额503，不形成无限队列 |
| 审核快照 | 当前最多1000实体、每实体最多100 aliases、快照最多512000 bytes；超限拒绝，不静默少用一半 |
| 相关性校准 | 单文件最多64KiB、只读；模型/配置/generation/词法revision/路径精确绑定。校准工具最多100000行、64MiB；每通道至少5正例/5负例及2家族只是工具下限，不构成统计充分性保证 |

配置可调整部分预算，但不能因此声称生产SLA达标。10并发与10QPS是不同维度；吞吐和尾延迟需要硬件、网络、模型、语料规模、缓存状态与并发入库条件。

## 4. 超时、取消与故障

`/v2/search`和`/v2/evidence/query`完整ASGI入口建立一个绝对预算；鉴权/配置依赖、召回、重排、关系、PG最终复验、问题项评估及版本重试共用，响应提交前再次检查。路由初始化在lifespan就绪前完成，不以先发一个业务请求作为正确取消的前提。在线模型和OS使用原生异步HTTP，超时/断连取消并等待请求分支收尾。同步线程和阻塞事件循环的CPU计算不能被强行中止；截止后不得再启动后续检索，超期计算完成也不能提交成功证据。PG快照批次放在独立线程，用剩余statement_timeout/lock_timeout、短连接池等待和驱动cancel请求限制；网络建立/取消交接的清理可能晚于HTTP预算，真实驱动取消和连接释放仍需目标PG故障验收。不能宣称HTTP超时等于外部GPU计算已停止。

只有完成PG最终复验的证据可以返回；PG授权不可用不返回旧缓存/未校验正文。V2 per-process租约不是跨API进程、Worker和外部模型的全局配额；批量编码与在线服务的全局资源隔离尚未实现。

## 5. 更新、持久化和运行限制

空库初始化与既有库升级共用带checksum的迁移链。支持核验后的evidence-v2.4完整基线升级；更早/残缺结构或未知迁移摘要拒绝升级，须单独核实。已有目录不会重新执行init SQL，必须显式运行cuekb-db upgrade。

原件、PG与模型配置加密密钥必须一起备份；OpenSearch可重建。更新为整文件新版本；新profile新块ID；restore派生新ID避免旧outbox误删。未标注的产品归属保持unknown，需明确补标/重处理。

generation只重编码当前PG块，build_source_profiles是构建快照，不是active索引实时库存。旧投影缺少V2或scope-lexical-v2.3标记时搜索返回409，需要重建；ready对此返回503 INDEX_UPGRADE_REQUIRED；旧profile正文不足不能靠重建修复。profile/别名/映射快照不可变，修改需要新处理版本。evidence-v2.5不静默重解释旧快照；数据库升级保留旧发布事实，源文档树须从原件重处理成新版本。

删除是软删除与投影异步清理，不承诺原件硬删除、备份清除期限或恢复SLA。没有应用级查询结果缓存、自动生成金标/充分性校准、自动澄清、对象存储连接器、OIDC或HA自动故障切换。可选相关性门控只消费人工标注的评分校准文件，未提供实测生产阈值。memory模式重启丢数据、不鉴权、无生产向量/PDF链路，仅用于开发。

部署默认Compose HTTP 8085，未内置公网TLS。远程系统需自行提供TLS/私网访问控制；API Key不得放URL或发给浏览器以外的非授权主体。反向代理应限制总请求体和连接/上传时限，不把50MiB文件限制误当所有网关请求天然有相同上界。

审核CPU规则不要求LLM/GPU；检索Embedding配置仍必需。当前规则不保证识别隐含指代、所有语种、错位/合并表格或所有远距限定。未知产品/歧义保留待办，不以提高自动确认比例牺牲准确性。Worker解析默认180秒（CUEKB_WORKER_PARSE_TIMEOUT_SECONDS，5—1800秒），独立进程超时可终止；现有查询/模型预算不因此增加。

明确单品、套件和比较的范围不能由产品名提及或组件关系传递。审核通过只认证归属/结构规则，既不保证原文为真，也不将evidence_status改成sufficient。已发布版本、事实归属和模板不原地更新；新版本必须分别生成与发布。

S1源树、320词法token分窗及必要闭包不等于通用语义理解。Docling资源不可用仍会使PDF/OCR失败。规范树每版最多30000节点/100000边/10000检索单元；结构API分页最多100节点，节点文本预览最多10000字符、各来源span文本预览最多500字符，相关边最多2000并显式截断。

问题级`structured-support-1`只把源节点可追溯、主体明确、必要关系完整且显式属性覆盖的问题项认证为direct；保守形态规则和受控storage/shipping概念归一不构成通用自然语言蕴含模型。未配置支持校准器，当前不会输出entailed；跨语言改写、隐含因果、远距指代和未知领域同义词可能返回unassessed。absent只针对本次授权来源和有界计划。当前continuation不签发二次查询token，服务内部补召回结束后均为终态。

standard交付的`cuekb-unicode-lexical-v1`只对该标准视图具有精确定义，不是Nano tokenizer。voice profile必须加载运行方提供的实际Hugging Face tokenizer JSON及不可变ID；未配置即409。登记文件与实际VoiceChat镜像是否同源仍需部署身份和现场token对照验证。
